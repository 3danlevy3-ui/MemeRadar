# MemeRadar: סורק מוקדם למניות מם

הסורק רץ כל 15 דקות ועוקב אחרי שלושה מקורות שיח:
- **Reddit:** WallStreetBets ועוד 6 סאבים.
- **Stocktwits:** רשימת הטרנדינג וקצב ההודעות לכל מניה. חינם.
- **X:** בתשלום, עם תקציב יומי קשיח.

כשמניה מתחילה "להתפוצץ" באחד המקורות, הוא בודק גם את מבנה השוק (שורט אינטרסט מ-FINRA ופעילות אופציות מ-Nasdaq, שניהם חינם) ושולח התראה לטלגרם.

האות מתבסס על כמה מדדים יחד:
- כמה אזכורים היו בשעה האחרונה, לעומת הממוצע של 14 הימים האחרונים.
- כמה כותבים שונים הזכירו את המניה, כדי לסנן אדם אחד שמספים.
- מה נתח המניה מכלל השיח.
- מה מצב המחיר: ההתראה מסומנת 🟢 **מוקדם** אם המחיר עלה פחות מ-10% ב-24 השעות האחרונות, ו-🟠 **מומנטום** אם כבר עלה יותר.

אחרי כל התראה הסורק ממשיך לעקוב אחרי המניה, ושולח 🔴 **יציאה?** באחד מהמקרים הבאים:
- השיח דועך מתחת ל-35% מהשיא.
- המחיר יורד 15% מהשיא שנרשם מאז ההתראה.
- עוברות 72 שעות.

> ⚠️ זה כלי מחקר, לא ייעוץ השקעות. בבקטסט האות מצא תנודתיות, כלומר תנועה חדה לשני הכיוונים, ולא כיוון מובטח. פרטים בהמשך.

## התקנה (כ-15 דקות, חינם)

### 1. בוט טלגרם
1. בטלגרם, פתח את **@BotFather** ושלח `/newbot`. תן לבוט שם, ושמור את ה-**token** שתקבל.
2. שלח הודעה כלשהי לבוט החדש, למשל "hi".
3. בדפדפן, פתח את הכתובת `https://api.telegram.org/bot<TOKEN>/getUpdates` (עם ה-token שלך במקום `<TOKEN>`). ה-**chat id** הוא המספר שמופיע תחת `"chat":{"id": ...}`.

### 2. GitHub
1. היכנס ל-https://github.com. אם אין לך חשבון, פתח חשבון אישי.
2. לחץ **New repository**, קרא לו `memeradar` ובחר **Public**. ב-repo ציבורי, GitHub Actions חינמי בלי הגבלת דקות. הסודות (tokens) שמורים מוצפנים ולא נחשפים. ב-repo פרטי יש מכסה של 2,000 דקות בחודש, ולכן צריך לשנות את ה-cron ל-`*/30`.
3. **Add file → Upload files** וגרור את כל התוכן של התיקייה `MemeRadar`.
4. **Add file → Create new file**. בשם הקובץ הקלד `.github/workflows/scan.yml`, הדבק את כל התוכן של הקובץ `workflow_scan.yml` ולחץ Commit. זה הקובץ שמפעיל את הסורק כל 15 דקות.
5. **Settings → Secrets and variables → Actions → New repository secret** והוסף:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `X_BEARER_TOKEN` (לא חובה, בתשלום). בלי המפתח הזה הסורק פשוט מדלג על X. פרטים בסעיף "X" למטה.
   - `ANTHROPIC_API_KEY` (לא חובה). עם המפתח הזה, Claude קורא את הפוסטים ומוסיף להתראה את הסנטימנט, רמת ההייפ, האם מדברים על סקוויז, חשד לפאמפ וסיכום בעברית. אם אין לך מפתח, הסורק עובד גם בלעדיו.
6. **Actions → MemeRadar scan → Run workflow**:
   - קודם הפעל עם ✅ `test_telegram` וודא שהגיעה אליך הודעת בדיקה.
   - אחר כך הפעל בלי הסימון. הריצה הראשונה בונה בסיס של 72 שעות אחורה ולוקחת 15–30 דקות.
7. מכאן הסורק רץ לבד כל 15 דקות. GitHub לפעמים מאחר ריצות בכמה דקות.

## X (טוויטר)
ה-API של X עובד בתשלום לפי שימוש, בלי מנוי. יוצרים חשבון מפתח ב-console.x.com, קונים קרדיט (למשל $10) ומעתיקים את ה-Bearer Token.

מה הסורק עושה ב-X:
- **חשבונות במעקב** (`X_ACCOUNTS`, ברירת מחדל: TheRoaringKitty): כל פוסט חדש של חשבון ברשימה שולח התראה ⭐ מיד. אם החשבון לא מפרסם, זה כמעט לא עולה כסף.
- **ספירת פוסטים:** לכל מניה שכבר נדלקה ב-Reddit או ב-Stocktwits, הסורק סופר כמה פוסטים עם $TICKER היו בשעה האחרונה, לעומת 7 הימים האחרונים. עלות: כ-$0.005 לבדיקה.
- **רשימת מעקב** (`X_WATCHLIST`, ברירת מחדל: GME,AMC): בכל ריצה נבדקת מניה אחת מהרשימה, כדי לתפוס מהלכים שמתחילים ב-X.
- **תקציב:** `X_DAILY_BUDGET` (ברירת מחדל: $1 ליום). כשהתקציב נגמר, X נעצר עד חצות UTC.

## יומן ביצועים וסיכום שבועי
- כל התראה נרשמת ב-`state/journal.json`, יחד עם המחיר שהיה ברגע ההתראה.
- הסורק בודק לבד מה קרה למחיר אחרי יום, 3 ימים ו-10 ימים, ומחשב "עסקת ניסוי": מימוש ב-+30%, סטופ ב-−15%, עד 3 ימים, עלות 0.5%.
- **כל שבת ב-09:00** תגיע הודעת 📊 עם סיכום ועם גרף: כמה התראות היו, כמה מהן עלו 20%, כמה ירדו 15%, ואיזה מקור עובד הכי טוב.

## לוח בקרה בטלפון
בכל ריצה הסורק בונה דף אינטרנט, `docs/index.html`, עם גרפים וטבלה של כל ההתראות.
כדי להפעיל אותו: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, תיקייה `/docs` → Save**.
אחרי דקה-שתיים הדף זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-ה-repo>/`. כדאי להוסיף אותו למסך הבית בטלפון.

## כיוונון
את כל הספים אפשר לשנות ב-`scanner/config.py`, או דרך **Settings → Variables**:

| משתנה | ברירת מחדל | מה עושה |
|---|---|---|
| `MIN_MENTIONS_1H` | 8 | מינימום אזכורים בשעה |
| `MIN_AUTHORS_1H` | 5 | מינימום כותבים שונים |
| `BURST_MULT` | 5 | פי כמה מהממוצע השעתי |
| `EARLY_MAX_MOVE` | 0.10 | עד כמה המחיר רשאי לזוז ב-24 שעות כדי שההתראה עדיין תסומן "מוקדם" |
| `SUBREDDITS` | 7 סאבים | רשימה מופרדת בפסיקים |
| `X_DAILY_BUDGET` | 1.0 | תקציב X יומי בדולרים |
| `X_WATCHLIST` | GME,AMC | מניות שנבדקות ב-X גם בלי טריגר |
| `X_ACCOUNTS` | TheRoaringKitty | חשבונות X שכל פוסט שלהם שולח התראה |
| `TP_PCT` / `STOP_PCT` | 0.30 / 0.15 | כללי עסקת הניסוי |
| `HOLD_DAYS` | 3 | כמה ימים מחזיקים בעסקת ניסוי |
| `POSITION_PCT` | 2 | גודל מוצע לעסקה, באחוזים מהתיק (מוצג בהתראה) |
| `USE_TRENDS` / `USE_CHARTS` / `USE_EARNINGS` | 1 | 0 כדי לכבות |

## מבנה
```

```
